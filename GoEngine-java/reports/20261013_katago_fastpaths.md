## 使用边界

- 当前 APP 已经使用单次 NN 快速估分；新测速不是说 APP 在手机上达到上述毫秒数。
- 单次 NN 的白棋领先目数与规则终局得分并不是一回事；12 次搜索只能给潜在着法，不能判死活。
- 劫禁硬检查应来自应用自己的严格落子规则；KataGo 的 final_score 即使在劫争中也会返回预测。
- APP 快速显示劫禁/打吃信号，不追加推理；额外的局面检查按需执行 12 visits / 0.5s；完整死子判断单独进入。
- GitHub Actions 原始逐次数据参见 JSON；该报告可供之后设备 CPU/GPU 性能对照。
